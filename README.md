# 13 - AI 커밋/PR 초안 생성기 (ai-commit-pr-generator)

> 🚧 **미착수** — 디렉터리·레포 준비만 완료

`git status` / `git diff` 를 읽어 **커밋 메시지**와 **PR 제목·본문 초안**을 AI API 로
생성하는 터미널 도구. 핵심은 API 호출이 아니라 **어떤 컨텍스트를 넘겨 원하는 품질을 얻는가**다.

- 과제 원문: 로컬 `../13-ai-commit-pr-generator.md`
- Python 3.10 이상 · 웹 화면 없음(CLI 전용)

## 설치 및 실행

```bash
export AI_API_KEY="YOUR_KEY"     # 환경변수로만 관리 — 코드에 하드코딩 금지

./run.sh run commit              # 커밋 메시지 초안 생성
./run.sh run pr                  # PR 제목/본문 초안 생성
./run.sh test                    # 단위 테스트
```

Git 이 초기화된 **프로젝트 루트에서** 실행해야 한다. 변경 사항이 없으면 안내하고 종료한다.
`PYTHON` 환경변수로 인터프리터를 바꿀 수 있다 (3.10+ 필요).

## CLI 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--model` | _미정_ | 호출할 모델 |
| `--temperature` | _미정_ | 낮으면 결정적, 높으면 다양 |
| `--max-tokens` | _미정_ | 응답 길이 상한 |
| `--safe-mode` | _미정_ | 민감정보 마스킹 / diff 전송량 제한 |

## 출력 형식 규칙

| 항목 | 규칙 |
|---|---|
| 커밋 제목 | 50자 이내 권장 (최대 72자), 1줄 필수 |
| 커밋 본문 | 선택. 넣으면 변경 파일 1~3개 언급 **또는** 핵심 변경 1~2개 불릿 |
| PR 제목 | 최대 80자, 1줄 |
| PR 본문 | `Why` / `What` / `How to Test` 섹션 헤더 필수 + 각 섹션 최소 1개 불릿 |

위반 시 **검증 후 재생성** 또는 **후처리** 중 하나로 맞춘다(과제는 택1 허용).

## ⚠️ 주의사항

- **API Key**: 환경변수로만. `.env` 는 `.gitignore` 로 막혀 있다.
- **민감정보**: `git diff` 에 키·이메일이 섞여 들어갈 수 있다. `--safe-mode` 로 마스킹하거나
  전송량(파일 수 / 줄 수)을 제한한다.
- **비용**: 1회 실행당 API 호출 **1~2회 이내**로 제한한다. 호출 횟수를 로그에 출력한다.
- 생성된 문구는 초안이다. 사용자가 검토 후 적용한다.

## 범위 밖 (과제 §7 명시)

- Git 수집은 `git status` / `git diff` 까지
- `git push`, GitHub PR 생성(API 연동) 등 **원격 저장소 자동 반영은 구현하지 않는다**
